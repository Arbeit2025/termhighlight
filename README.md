# マイ用語集ハイライト（termhighlight）

自分用の用語集（単語と意味のリスト）を登録しておき、文章を貼り付けると、登録済みの用語が文章中でハイライト表示され、あわせて見つかった用語の意味一覧が示される、個人用の読解補助ツールです。zhtranslate（翻訳）と wikitranslate（Wikihonyaku）の用語集づくりの発想を、テキスト処理に特化した小さなツールとして切り出したものです。単一ファイル Flask + SQLite で作られています。

## 機能

- **用語の登録・削除**：用語（単語）と意味を登録できます。一覧から削除もできます。同じ用語をもう一度登録すると、意味が上書きされます。
- **文章のハイライト**：文章を貼り付けて送信すると、登録済みの用語が `<mark>` でハイライト表示されます。
- **意味一覧の表示**：文章中で見つかった用語は、意味とともに一覧で示されます（出現順、重複なし）。
- **長い用語を優先**：たとえば「学習」と「自己調整学習」の両方が登録されている場合、「自己調整学習」の方を優先してマッチさせるので、部分的な二重マッチは起きません。
- **XSS 対策**：ユーザー入力（文章・用語・意味）は必ず HTML エスケープしてから処理・表示します。

## ローカル実行

```bash
pip install -r requirements.txt
python app.py
# http://localhost:5000
```

DB のパスは環境変数 `TERMHIGHLIGHT_DB` で変更できます。

## テスト

```bash
python -m unittest discover -s tests
```

## Render へのデプロイ

`render.yaml` 同梱。無料プラン（free）の Web Service としてデプロイできます（healthCheckPath: `/healthz`）。

## 制限事項（正直なところ）

- **無料プランでは SQLite のデータが再デプロイ等で消える場合があります。** 登録した用語集が失われることがあるので、大事な用語集は別途メモしておいてください。
- ハイライトは完全一致（文字列の一致）のみです。表記ゆれや活用形には対応しません。
- ログイン機能はありません。個人利用を前提とした小さなツールです。
